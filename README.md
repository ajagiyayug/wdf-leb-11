================================================================================
PRACTICAL 11: Student Management CRUD
================================================================================

OVERVIEW:
This practical involves creating a complete Student Management module allowing admins
or authorized users to perform standard CRUD operations on student records in MySQL.

KEY FEATURES & OBJECTIVES:
1. Create (Insert), Read (Select), Update, and Delete operations for student profiles.
2. Search functionality by student name, email, or course using SQL parameters.
3. Filtering options for sorting or narrowing down student lists.
4. Client-side confirmation dialogs before executing delete operations.
5. Secure execution using parameterized SQL queries.

TECHNOLOGIES USED:
- PHP (MySQLi / PDO)
- MySQL Database
- HTML5 / CSS3 / JavaScript
